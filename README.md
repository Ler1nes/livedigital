# LiveRoom — платформа для созвонов

Локальная версия платформы с бесконечными комнатами (аналог Livedigital).
Чистый HTML/CSS/JS, без сборки. Видео/аудио/чат — P2P (WebRTC через [Trystero](https://github.com/dmotz/trystero), сервер не нужен).

## Запуск

1. Запустите **start.bat** (поднимает локальный сервер на порту 8000 и открывает браузер).
   Или вручную: `python -m http.server 8000` → http://localhost:8000
2. Чтобы проверить созвон с двумя людьми: откройте ссылку в двух разных браузерах
   (Chrome и Edge) или в обычном + инкогнито-окне.

## Возможности

- Главная страница: создание комнат с названием, список, копирование ссылки, удаление.
- Бесконечная ссылка `room.html?room=КОД` — студенты заходят в любой момент.
- Лобби: имя, предпросмотр камеры, включение/выключение камеры и микрофона.
- Звонок: сетка участников, тумблеры микрофона и камеры, демонстрация всего экрана,
  поднятая рука (иконка на плитке участника), боковой чат, выход.
- Состояния (камера/микрофон/рука) синхронизируются у всех в реальном времени.

## Структура

```
index.html   — главная (список комнат)
room.html    — лобби + комната
css/style.css
js/rooms.js  — логика главной
js/call.js   — логика звонка
js/ui.js     — общие хелперы
start.bat    — локальный сервер
```

## Ограничения

- P2P (mesh): до ~6–8 участников с видео одновременно.
- Список комнат хранится в localStorage браузера создателя (у других людей его нет,
  но ссылка работает у всех — название комнаты зашито в ссылку).
- Для видео нужен интернет: сигналинг идёт через публичные Nostr-релеи.

## Этап 2 (после ревью)

- Публикация на GitHub Pages: `https://<user>.github.io/<repo>/room.html?room=КОД`.
- Синхронизация списка комнат между устройствами (GitHub Gist API).
